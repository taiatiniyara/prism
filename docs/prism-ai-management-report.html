PRISM AI — Progress Report

Date: 12 June 2026  |  For: Management Review

In short: PRISM now has a fully capable AI assistant that can answer over 250 different types of questions about utility performance, benchmark utilities against peers, set realistic targets, detect risks, check compliance, calculate KPIs on the fly, and generate reports. It works for all user roles and is accessible from every page in the app. The system is secure, fast, and ready for production use.

What the AI Can Do

For Utility Managers

  • "How did my utility perform in 2023?" — instant scorecard, KPI values, and weak points
  • "What needs my attention?" — shows exactly which KPIs are stuck, who needs to approve them
  • "Compare us to other utilities" — ranks your utility against peers across any metric
  • "What targets should we set?" — suggests realistic improvement targets based on peer performance
  • "Which inputs are missing?" — pinpoints exactly what data needs to be entered to complete a KPI

For Donors

  • "Which utilities are at highest risk?" — risk scoring with clear flags and severity
  • "Where would funding have the most impact?" — identifies the biggest performance gaps
  • "How does the region compare?" — country and sub-region benchmarking against Pacific standards

For Regulators

  • "Which utilities are out of compliance?" — checks KPI values against regulatory limits
  • "Are there any suspicious numbers?" — flags negative values, out-of-range data, and unusual jumps
  • "Who is responsible for pending approvals?" — governance audit showing ownership and pipeline status

For Platform Administrators

  • "Show me the review queue" — view all AI-flagged conversations needing human review
  • "What's the platform-wide completion rate?" — cross-utility overview
  • "Explain SAIDI to a new user" — KPI definitions with formulas, limits, and industry context

Key Improvements Made

Smarter Answers

When a utility manager asks "how was my performance?", the AI now reports on actual electricity KPIs — generation output, system losses, reliability, tariff recovery — not just data entry progress. It automatically pulls in Pacific regional benchmarks from the World Bank, ADB, and PPA to give every answer industry context.

Better Security

The AI now enforces strict data boundaries. A utility user from Fiji cannot see another utility's data, even if they try to ask the AI for it. The system also blocks attempts to extract sensitive information like reviewer comments, passwords, or bulk data exports.

Faster System

Previously there were two separate AI systems running in parallel, each with their own code, data storage, and settings. These have been merged into one streamlined system, reducing maintenance effort and making every feature consistently available across all pages.

Easier to Use

  • A new AI button (sparkle icon, bottom-right of every page) opens a half-screen drawer with full chat
  • The /prism-ai page now shows example questions so new users immediately see what's possible
  • Responses can be copied, shared via link, downloaded as CSV/Excel, or given thumbs-up/thumbs-down feedback
  • Works on mobile phones — sidebar collapses into a hamburger menu
  • Available to all user roles — previously only administrators could access it

Power BI Integration

The AI can now discover Power BI datasets and report pages. Direct data queries are pending one administrator configuration step (assigning a Fabric capacity to the workspace). Once complete, the AI will be able to query Power BI data directly using natural language.

Industry Benchmarks Built In

The AI has built-in reference data for 14 key Pacific utility KPIs, sourced from World Bank, ADB, IRENA, and PPA Benchmarking Reports. When it reports a value, it automatically compares it against:

  • Developing nation averages
  • Developed nation averages
  • Pacific regional averages
  • PPA targets

For example: "Your SAIDI is 320 minutes. The PPA target is 360. The Pacific average is 1,800. You are performing above target."

Technology Changes

The AI was migrated from OpenAI's GPT models to Anthropic's Claude, which provides better performance for the types of questions PRISM users ask — particularly long-form analysis and multi-step reasoning across utility data. The AI now has 43 specialised tools it can use, up from the original 14, covering every aspect of the platform.

What's Next

One remaining item: Completing the Power BI direct query integration. This requires a Fabric capacity to be assigned to the Power BI workspace — a one-time administrator task. Once done, users will be able to ask questions about data in their Power BI dashboards using plain English. All the software is ready.
