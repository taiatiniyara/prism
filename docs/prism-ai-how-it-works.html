2. What Happens Step by Step?

Step 1 — You type a question
"How does my utility compare to other Pacific utilities on SAIDI?" — just like talking to a colleague. No special syntax, no query language.
Step 2 — Security check
The system verifies your identity, checks your access level, and validates that the request is legitimate. Takes milliseconds. You don't see this — it's fully automatic.
Step 3 — The AI understands your intent
It recognizes you're asking about reliability benchmarking and matches your question to the best pre-built query. In this case: saidi_by_utility.
Step 4 — Data is fetched
The AI sends a query to Power BI (or the PRISM database as backup) to pull actual SAIDI values for all utilities in your chosen fiscal year. This is the same data that feeds the PRISM dashboards.
Step 5 — Analysis runs
The AI ranks the results, identifies your utility's position, checks for outliers, and prepares context — like how you compare to PPA benchmarks and Pacific averages.
Step 6 — The answer streams back
You see the answer appear character by character — like someone typing. A "Thinking" dropdown (collapsed by default) shows what the AI checked behind the scenes if you're curious.

7. Safety & Guardrails — Built In, Not Added On

🛡 Sensitive Data

Identity: Every request requires authentication — only authorized PRISM users can access the AI.
Origin Check: Requests must come from the PRISM app — not from external websites or automated scripts.
Rate Limiting: Max 20 questions per minute, 100 per 15 minutes — prevents abuse and ensures fair access for all users.
PII Filtering: Email addresses, phone numbers, and credentials are automatically stripped from both your questions and the AI's answers.
Anti-Hallucination: The AI is explicitly instructed never to fabricate data. If data is missing, it tells you honestly — no guessing.
DAX Validation: All Power BI queries are validated to be read-only — destructive commands are blocked before they reach the database.

10. What Happens When Something Doesn't Work

Scenario 1: Power BI dataset refresh failed
AI tries query → Power BI returns error → AI switches to PRISM database immediately
Note: The AI only tries ONE Power BI query before switching. It doesn't keep retrying — that would waste time.
Scenario 2: Data hasn't been submitted yet
AI tries both sources → both return empty → AI tells you honestly: "This data isn't available yet."
It suggests what to check and offers alternative data that IS available.
Scenario 3: Question doesn't match any tool
AI can't find a query match → AI asks you to clarify or suggests related topics
For example: "I don't have data on that specific topic. Would you like to see your overall performance instead?"
