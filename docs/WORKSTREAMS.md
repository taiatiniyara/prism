## Protocol for every session

1. **On start:** read this file top-to-bottom before doing anything.
2. **When your status changes** (start/pause/block/finish a chunk, or hit/clear a dependency): update *your own row* — status emoji, the `Last update` date, and one line on what changed.
3. **Editing etiquette:** only edit your own stream's section (+ this shared area if a dependency between streams changes). Keep entries terse — this is a dashboard, not a log.
4. **Dates are absolute** (YYYY-MM-DD). Today when seeded: 2026-07-24.
5. If you pick up a stream that has no owning session yet, put your session name in `Owner`.
6. **User-impact ledger (added 2026-07-28, Eugene-directed):** if your change alters what any user *sees, enters, or configures*, add a row to [USER-IMPACT.md](USER-IMPACT.md) **in the same commit** — roles affected, journey delta, instructions needed. #15 audits gaps on refresh. The ledger, not memory, is where release-time user guides come from.
7. **Commit hygiene — every stream, every change (added 2026-07-26):** land work via **feature branch → pull request → squash-merge with a real, descriptive message** (e.g. PRs #50/#51). **Do NOT commit work-in-progress straight to `main`,** and never with placeholder/gibberish messages (`wed`, `ccss`, `dde`, `eec`, `newest`…). Squash-merge keeps the messy WIP on the throwaway branch so `main`'s history stays readable, reviewable, and bisect-able. Existing junk-message history is **left as-is** — rewriting shared history force-pushes over everyone's clones and any branch based on those commits.
