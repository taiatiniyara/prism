2. Data Flow

User → ChatPanel (React) → POST /api/ai/chat
  → Auth (getCurrentUser) → Origin validation → Rate limit check
  → Input guardrails (PII, injection, length)
  → Session/Turn creation (DB transaction)
  → System prompt assembly (base + role + context)
  → runAiStream() with 67 tools
    → Primary: claude-sonnet-4-6 (with extended thinking)
    → Fallback: claude-haiku-4-5-20251001 (on error)
  → Combined SSE stream (text + reasoning + tool events)
  → Client: requestAnimationFrame character-by-character reveal
  → onFinish: persist response to DB, record usage, summarize
